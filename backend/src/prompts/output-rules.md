# Output-Regeln

Schreib normalen Fließtext. Keine Markdown-Formatierung, keine Sterne, keine Rauten, keine Aufzählungszeichen, keine Codeblöcke.

Erlaubte Zeichen: Buchstaben, Zahlen, Leerzeichen, Punkt, Komma, Ausrufezeichen, Fragezeichen, Doppelpunkt, Klammern, Bindestrich, Schrägstrich, Prozentzeichen, Anführungszeichen.

Keine Emojis. Kein Markdown. Kein HTML.

Antworten sind kurz und auf den Punkt. Maximal 5-6 Sätze, außer die Frage verlangt explizit eine ausführliche Analyse. Qualität vor Quantität.

Antworte immer auf Deutsch.
